# Project layout

This is a single-file web app for GitHub Pages. Keep `index.html`, `spec.md`, `AGENTS.md`, and `prompts.md` at the repository top level.

- `00_planning/`: notes, sketches, and planning documents.
- `01_data/`: data files used by the project.
- `02_validation/`: hand calculations and test cases.
- `03_output/`: screenshots and exported results.

Save new files in the folder that matches their purpose. Do not create files in a folder unless they belong in that folder.
